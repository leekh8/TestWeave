# TestWeave 위험 수용 등록부
#
# 고칠 수 없거나 당장 고치지 않기로 한 미충족 항목을 여기에 적는다.
# 적힌 항목은 기한까지만 미충족 집계에서 빠진다. 판정 자체는 그대로 FAIL이다.
#
# 형식 (칸 5개, 구분자는 |)
#   대상URL | 모듈 | 규칙 | 기한(YYYY-MM-DD) | 사유
#
# 규칙 이름은 리포트에 나오는 그대로 적는다. 한 글자라도 다르면 적용되지 않고,
# 그런 줄은 스캔 로그에 "쓰이지 않은 수용"으로 뜬다.
#
# 지키는 선
#   - 회귀와 소멸은 수용할 수 없다. 등록해 둬도 "수용 무효"로 표시만 되고 적용되지 않는다.
#     수용은 "지금 상태를 알고 있다"는 선언인데, 회귀는 상태가 바뀐 것이라 전제가 깨진다.
#   - 기한은 필수다. 무기한 수용은 잊힌 수용과 구별되지 않는다.
#   - 기한 상한은 1년이다 (testweave.exceptions-max-days).
#   - 사유가 없으면 기동이 실패한다. 다음 사람이 판단을 이어받을 수 없기 때문이다.
#
# 이 파일은 일부러 저장소에 커밋한다. 누가 언제 무엇을 왜 수용했는지가 git 이력에
# 남아야 감사 증적이 된다. 공개하면 안 되는 업무 대상은 exceptions.local.txt에 두고,
# 그 파일이 있으면 그쪽이 이긴다 (gitignore 대상).
